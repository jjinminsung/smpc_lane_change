# 수정 계획 v2: 반응형 예측 + 트리 단독 판단 (2026-11-04 확정)

브랜치 `research/tree-planner`. 이 문서는 작업 목표이자 체크리스트다. 단계마다 **완료 기준**을 만족해야 다음으로 넘어간다.
인지는 앞으로도 GT(`/Object_topic`)만 쓴다(LiDAR 없음).

## 1. 왜 바꾸나 (MORAI 단계 H, 시뮬 진단에서 확인한 것)

| 문제 | 근거 |
|---|---|
| 트리 판단이 기존 판단과 차이 없음 | 뒤차 가속 확률(GT 표)이 평소 0.006–0.007 ≪ ε 0.04. 관측된 가속은 '계속'만 허용 → 열린 루프와 같음. 시뮬 200 에피소드 판단 일치 96 % |
| 정지 출발 합류 불가(승인) | 합류 뒤 자차 속도를 11 km/h 로 예측(`v_post = min(미션 3.15 m/s, 앞차)`), 실제는 4 s 26 km/h·8 s 40 km/h. 뒤차 비양보 가정 → 요구 뒤 간격 약 65 m |
| 승인 직후 복귀(실행) | 모니터 '계속' 예측이 앞차를 무시하고 32 km/h(연결 경로 상한)까지 가속 → 서행 앞차와 충돌로 봄. 뒤차 없는데 0.8 s 만에 복귀 (v4_H_H_s30_d40_tree_nogate_r0) |
| 접근 중 끝내 정지 | 자차 56–62 km/h, 목표 차선 40 km/h. 양보 후보 감속폭 최대 3 m/s 로 못 맞춤. 앞차 급제동 확률(경험식) 0.65 |
| 정체 버그 | 복귀 반복으로 차선 끝 20 m 안에 서면 경로 미리보기가 짧거나 무효 → 차량 0 대로 60 s 이상 승인 불가 |
| 확률 근거 약함 | 앞차 급제동은 측정 없는 경험식(0.05–0.65). 뒤차 가속 표는 대기열 출발이 섞였을 수 있음 |

## 2. 최종 구조

```
 /Object_topic (GT: 위치·속도·가속도)
   ▼
 반응형 예측 (자차와 타겟 차량을 함께 시뮬레이션)
   자차: ACC 폐루프 = ACC 법칙(앞차 추종·차선 끝 정지·상한) + 미션 속도 회복 + MPC 추종 응답
   뒤차: 기본 = 자차가 목표 차선에 들어오면 반응 지연 뒤 자차를 앞차로 보고 따라감(양보)
         예외 = 양보 안 함/늦음                         확률 p_rear (최솟값 0.05)
   앞차: 기본 = 자기 앞차를 따라감
         예외 = 이유 없는 급제동 / 급가속                 확률 p_front (최솟값 0.05)
   ▼
 트리 판단 (차선 변경 전)
   후보 행동 × 가지(기본·예외 조합) × 대응(계속 / 복귀)
   매 예측 시점 Σ 확률 × 위험 ≤ ε, 그중 기대 비용 최소
   남는 조건: G1(목표 차선), G2(궤적 생성), 승인–모니터 일치. 목표 차선 뒤·옆 차량 모두 고려
   ▼ 차선 변경 시작
 실행: 기본 ACC + 경로 (특별한 명령 없음)
   ▼ 20 Hz
 모니터: 같은 예측·같은 계산을 매 틱 다시
   반응 지연이 지났는데 기대한 감속이 없으면 예외 확률 ↑ (두 가설 베이즈 갱신)
   계속 위험 > 2ε 가 2 틱 연속이고 복귀가 더 안전 → 복귀
   ▼
 supervisor 복귀 (모니터 0.3 s 끊기면 rear_abort 폴백)
```

원칙
- 새 동작은 모두 파라미터로 켠다. 끄면 지금 동작(기존 SMPC, 현재 D)이 그대로 재현돼야 한다.
- 판단과 모니터는 같은 예측 코드를 쓴다. C++ 과 파이썬은 같은 식이고 일치 테스트로 확인한다.
- M2/M8 경로·계획은 건드리지 않는다. 대회 스택(total_bringup 등)은 고치지 않는다.

## 3. 작업과 완료 기준

### 단계 1. 자차 ACC 폐루프 예측
- [ ] 1a. MORAI bag 으로 제어기 응답 측정: 기준 속도 `min(미션, /smpc/target_speed_mps_gated)` → 실제 속도.
      1 차 지연 τ, 가속·감속 한계 맞추기 (`analysis/m6_ego_response.py`).
- [ ] 1b. 미션 속도 모델: 정지·차선 끝 값, 차선 전환 뒤 회복률(관측 +3 m/s/s).
- [ ] 1c. 파이썬 예측기: ACC 법칙(`sim/smpc_sim/acc.py` 재사용) + 응답 모델을 예측 구간 동안 굴림. 앞차는 가지별 예측을 받음.
- [ ] 1d. 검증: MORAI 기록에서 예측 vs 실제.
- **완료 기준**: (i) 응답 모델 4 s 뒤 속도 오차 중앙값이 지금 모델보다 작음.
  (ii) 정지 출발 합류 사례에서 4 s·8 s 뒤 예측 속도가 실제와 ±2 m/s 이내(지금은 −4/−8 m/s).
  (iii) 서행 앞차 뒤 출발 사례(v4_H_H_s30_d40_tree_nogate_r0 102 s, 107 s)에서 예측 충돌이 사라짐.

### 단계 2. 반응형 타겟 차량 예측
- [ ] 2a. 뒤차 기본 = 침범(자차 차체가 목표 차선에 들어온 깊이 ≥ 기준) 뒤 지연 t_r, 자차를 앞차로 보고 따라감(감속 한계 b_y).
      초기값은 시뮬 NPC 가정(침범 0.3 m, ≤ 6 m/s²) 과 M5 측정(지연 약 1–1.5 s)을 쓰고, 단계 5 측정으로 바꾼다.
- [ ] 2b. 앞차 기본 = 자기 앞차(GT) 따라감. 앞차의 앞차가 없으면 현재 속도·GT 가속도로 짧게 외삽 뒤 유지.
- [ ] 2c. 예외 가지: 뒤차 비양보(속도 유지), 앞차 급제동(−2.5 m/s²)·급가속(+1.0 m/s²). 확률 최솟값 0.05.
- [ ] 2d. GT 가속도(`/Object_topic` acceleration.x) 를 그대로 쓰는 경로(target_selector → 결정 노드).
- **완료 기준**: 단위 시험(뒤차 양보 시 간격이 지켜짐, 비양보 시 지금과 같은 위험), MORAI 기록 재생에서 타겟 차량 2 s·4 s 위치 오차가 등속 예측보다 작음.

### 단계 3. 시뮬 통합
- [ ] 3a. 트리 가지를 '기본·예외 조합'으로 교체(뒤차 2 × 앞차 3 이하). 확률 = 기본 1 − Σ예외.
- [ ] 3b. G6/G7/G8 제거(플래그), 트리 차량 집합을 목표 차선 뒤·옆 모든 차량으로.
- [ ] 3c. 모니터가 판단과 같은 예측 사용 + 관측 갱신(반응 지연 지난 뒤 감속 없음 → 예외 확률 ↑).
- [ ] 3d. 계산 시간 측정.
- **완료 기준**: 플래그를 끄면 기존 결과(시드 2000–2199)가 비트 단위로 같음. 판단 p99 ≤ 50 ms(파이썬은 참고치).

### 단계 4. 시뮬 비교
- [ ] 같은 시드 200 → 1000: 기존 SMPC / 현재 D / 새 구조 / 새 구조-가지 없음(기본 예측 하나).
- [ ] 예외 최솟값 0.05·0.1·0.2, 모니터 문턱 2ε·3ε·5ε 민감도.
- **완료 기준**: 새 구조가 D 대비 합류 시간이 같거나 짧고 성공이 같거나 높으며 자차 차선 변경 중 충돌이 늘지 않음.
  아니면 원인 분석을 기록하고 설계로 돌아간다.

### 단계 5. MORAI NPC 반응 측정 (MORAI 가 비어 있을 때)
- [ ] 뒤차 간격 10–40 m, 접근 속도 여러 값에서 일부러 합류(가능하면 `gap_test_decision` 노드).
- [ ] 반응 시작 침범 깊이, 지연, 감속 크기, 무반응 여부 → 2a 파라미터 확정. 기존 bag 중 실제 양보가 필요했던 사건은 2 건뿐이다.
- **완료 기준**: 30 건 이상, 파라미터와 분포를 `results/m7_npc_reaction.json` 에 저장.

### 단계 6. C++ 이식 + 정체 버그
- [ ] 6a. 결정 노드에 ACC 폐루프 예측·반응형 예측·새 가지·모니터 통일(모두 파라미터, 기본값 = 지금 동작).
- [ ] 6b. C++ ↔ 파이썬 일치 테스트 확장(위험·트리·모니터·ACC 예측).

      (b) 차선 2 끝 미리보기 무효는 `/path_switch_preview` 를 녹화해 원인 확정 뒤 수정.
- **완료 기준**: 일치 테스트 통과(차 ≤ 1e-9 또는 판단 동일), 빌드 성공, 재현 시나리오에서 정체가 사라짐.

## 6. 관련 문헌
- Nair et al., *Predictive Control for Autonomous Driving With Uncertain, Multimodal Predictions*, IEEE TCST 33(4), 2025:
  다중 mode 확률 제약 + mode 별 피드백 정책. 타겟 차량 예측은 자차에 반응하지 않는다(식 5).
  이 계획의 차이 = 자차 진입에 반응하는 타겟 차량 예측 + ACC 폐루프 자차 예측.
- Bae, Moon, Seo, ACC 2020 (arXiv 1909.05665): 자차 후보 행동을 입력으로 받는 반응 예측 + MPC.
  나중에 데이터가 쌓이면 예외 확률을 이런 학습 모델로 바꿀 수 있다.
