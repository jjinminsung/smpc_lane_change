# 시나리오 트리 SMPC 로 고속 연속 합류의 보수성 줄이기

진민성 · 2026-11-04 (초안, MORAI 결과는 실험 종료 후 채움)

## 요약

고속도로 합류 구간(차선 0→1→2→3, 각 차선 끝 106/404/418 m)에서 확률적 행동 결정기(SMPC)는 "뒤차가 가속할 수도
있다"는 가능성만으로 차선 변경을 막는다. 원인은 차선 변경 후의 대응을 평가에 넣지 않는 열린 루프 구조와, 확률 제약
위에 겹친 결정론적 게이트다. 우리는 mode 가 드러난 뒤의 대응(계속·가속·복귀·제동)을 시나리오 트리로 함께 평가해
확률 제약 Σ_j p_j r_j(k) ≤ ε 하나로 판단하게 했다. 측정 기반 시뮬레이터(같은 시드 200 개)에서 합류 시간은 20.1 s
줄고(95 % CI −26.7 ~ −13.5 s) 성공률은 22 %p 올랐으며(+14.5 ~ +30.0) 충돌은 0 이었다. 대응 없이 게이트만 걷어내면
충돌이 10.5 % 생겼다. MORAI 결과: (채움).

## 1. 문제

기존 SMPC(이 저장소 `src/`, dd1cf54)는 후보 행동(지금 변경, t_LC 4개 × 유지/양보 4단계/가속)을 하나씩 평가한다.
주변 차량은 mode 2 개(앞차 정상/급제동 −2.5, 뒤차 정상/가속 +1.0 m/s²)로 예측하고 8 s(40 × 0.2 s) 동안
스텝별 충돌 확률을 계산한다.

- **열린 루프:** 후보마다 궤적이 하나로 고정되고, 뒤차 가속을 알아챈 뒤의 복귀·가속이 위험도에 없다.
  실행에서는 supervisor 의 `rear_abort` 가 대응하므로 평가와 실행이 어긋난다.
- **사실상 최악 판단:** 모든 mode 의 clearance ≥ 0 조건은 확률과 무관하다. 뒤차 가속 확률(표 최솟값 0.11)이
  ε 0.04 보다 커서 그 mode 에 충돌 가능성이 있으면 곧바로 차단된다.
- **중복 게이트:** 간격(14 m / 9 m), TTC 3 s, 헤드웨이, 장면 관측 1.5 s 가 확률 위험 위에 AND 로 겹친다.

## 2. 방법

**시나리오 트리.** 루트 a0 = 기존과 같은 후보 집합. 가지 j: 정상 / 뒤차 가속(시작 0·1·2·3 s) / 앞차 급제동.
분기 시점 t_b = 사건 시작 + 감지 지연(GT 49 Hz 에서 1 m/s² 가속이 필터 0.5 를 넘는 데 0.29 s → 0.5 s).
가지별 대응: 정상 = 계속, 뒤차 가속 = {계속, 계속+가속, 복귀, 복귀+감속}, 앞차 급제동 = {계속, 제동, 복귀}.
복귀는 목표 차선 경계(1.75 m) 전까지만. 루트마다 대응 조합(최대 768 개)을 전부 열거해

    min_c Σ_j p_j J_j(a0, c_j)   s.t.  모든 k 에서 Σ_j p_j r_j(a0, c_j, k) ≤ ε

를 푼다. 이산 대응을 열거하므로 위험 배분이 조합 선택 안에서 근사 없이 정해진다(Nair et al. TCST 의 피드백 정책을
행동 결정 수준으로 옮긴 형태). 기대 비용이 가장 낮은 루트를 실행하고 20 Hz 로 다시 푼다. 차선 변경 중에는
"지금 계속(이후 분기 허용)" 과 "지금 복귀" 두 루트를 같은 방식으로 비교해(문턱 2ε) `rear_abort` 를 대체한다.

**게이트 정리.** (표: 제거 G3, G5, 모든-mode clearance / 유지 G6, G7, G8, 정상 가지 clearance — 본문 표 참고)

**GT 인지.** LiDAR 트래커는 차선 변경 중 뒤차 검출률 중앙값 18 %, 등속 차량의 가속도 오검출 31 % 였다.
판단 로직만 검증하기 위해 MORAI Object Info(GT)를 쓰고 경로를 검증했다: 오프셋, 후륜축 기준점(+1.25 m),
heading 보정, UDP 중복 프레임(가속도를 0.56 배로 읽던 문제), 자차 시각 동기. 재검증 후 차선 배정·역할 100 %.

## 3. 실험 환경

- **C++ 일치:** 파이썬 이식은 원본 노드 소스를 include 한 하네스와 비교해 위험도 6.7e-16, 트리 평가 8.6e-15 이내로 일치.
- **시뮬레이터:** 1 차원 Frenet, MORAI bag 53 개에서 잰 NPC(스폰 13.9 m/s → 1.45 m/s² 가속 → 23.6 m/s,
  차선별 스폰 간격·최대 대수, 차선 끝 강제 합류 v≈10 m/s·횡 2.4 m/s), 자차 횡이동은 실측 진행률 곡선(4.34 s).
- **MORAI:** 회전교차로 뒤 고속도로 진입부 출발, 시나리오 S1–S4 + 스폰/목표 속도 격자 12 개, 방법별 반복.

## 6. 한계

- 예측 mode 는 손으로 정한 고정 가속도, NPC 는 MORAI 실측 분포에 맞춘 근사다. 사람 운전자에게 일반화되지 않는다.
- 상호작용(끼어들면 양보할지)을 예측하지 않는다. MORAI NPC 는 차선 끝에서 강제 합류해 합류 직후 접촉이 생겼다.
- 형식적 안전 보장은 없다. 안전은 확률 제약과 남긴 hard safety 에 의존한다.
